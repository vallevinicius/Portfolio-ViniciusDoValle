## Sobre

Portfólio de página única feito com React, TypeScript e Vite. A seção de projetos é carregada em tempo real pela API do GitHub, então acompanha os repositórios atualizados mais recentemente.

## Funcionalidades

- Seções de apresentação, projetos, certificações e contato
- Projetos buscados na API REST do GitHub (`vallevinicius`)
- Animações de revelação no scroll e fundo animado

## Stack

| Camada | Tecnologia |
|---|---|
| Front-end | React, TypeScript, Vite |
| Dados | GitHub REST API |

## Como rodar

**Pré-requisitos:** Node.js 20+

```bash
npm install
npm run dev        # http://localhost:5173
```

### Scripts

| Comando | Descrição |
|---|---|
| `npm run dev` | Servidor de desenvolvimento |
| `npm run build` | Build de produção |
| `npm run lint` | ESLint |
