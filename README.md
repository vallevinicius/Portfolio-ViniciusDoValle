## About

Single-page portfolio built with React, TypeScript and Vite. The projects section is loaded live from the GitHub API, so it stays up to date with the latest pushed repositories.

## Features

- Hero, work, certifications and contact sections
- Projects fetched from the GitHub REST API (`vallevinicius`)
- Scroll reveal animations and animated background

## Tech stack

| Layer | Technology |
|---|---|
| Front-end | React, TypeScript, Vite |
| Data | GitHub REST API |

## Getting started

**Prerequisites:** Node.js 20+

```bash
npm install
npm run dev        # http://localhost:5173
```
